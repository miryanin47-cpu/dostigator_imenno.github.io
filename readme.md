# Мотиватор 🎯

Веб-приложение для мотивации школьников. Помогает детям ставить задачи, зарабатывать баллы и накопления за выполненные дела, а родителям помогает отслеживать прогресс.

## Возможности

✨ **Система задач**: предустановленные или собственные задания для выполнения:
- Домашнее задание
- Посещение тренировки
- Получение пятерки
- Чтение книги
- Уборка комнаты

💰 **Заработок и накопления**: баллы и рубли за каждое выполненное дело:
- Настраиваемый курс: сколько рублей стоит один балл
- Месячный лимит рублей: деньги начисляются дням по порядку, пока лимит не выбран, баллы при этом не теряются
- Итог за день и история начислений за прошлые дни

📊 **Прогресс и статистика**:
- Текущая серия выполнений (если сегодня еще ничего не сделано, показывается серия до вчера)
- Результат дня и накопления за месяц
- Календарь с результатом за любой прошедший день
- Недельный и месячный отчеты: баллы, выполненные задания, активные дни и лучший день
- Графики (Chart.js лежит рядом, интернет для них не нужен)

🔐 **Две роли**:
- Родитель: управление параметрами, просмотр статистики
- Школьник: выполнение задач, заработок

PIN родителя задается при первом входе в режим родителя и спрашивается при каждой загрузке страницы. Это защита от случайных изменений, а не шифрование: данные лежат в localStorage браузера.

## Технология

- **HTML5**: структура
- **CSS3**: адаптивный дизайн с переменными
- **JavaScript (Vanilla)**: логика приложения
- **LocalStorage**: локальное хранилище данных
- **Chart.js 4**: визуализация статистики (`chart.umd.min.js`)
- **Google Fonts**: типографика (DM Sans, Manrope), без интернета подставляются системные шрифты
- **Service Worker**: офлайн-режим и установка на телефон

## Установка

1. Откройте `index.html` в браузере. Для офлайн-режима и установки на телефон нужен сервер: откройте папку по адресу `http://` или `https://`, а не файлом с диска.
2. Приложение готово к использованию.

При размещении на хостинге в подпапке (например, `https://сайт/мотиватор/`) ничего менять не нужно: все пути в приложении относительные.

## Публикация на GitHub Pages

В репозиторий должны попасть все 13 файлов из этой папки, в корень, без вложенных папок. Веб-интерфейс GitHub сохраняет только файлы, поэтому проект специально сделан плоским.

Проверка после публикации: откройте `https://<адрес>/icon-192.png` (должна открыться картинка) и `https://<адрес>/chart.umd.min.js` (должен открыться скрипт). Если обе ссылки отвечают 404, файлы не загружены.

Служебные файлы `sw.js` и `manifest.json` должны лежать рядом с `index.html`.

## Использование

### Для школьника
1. Откройте приложение
2. Переключитесь на роль «Школьник» (кнопка ⇄)
3. Выполняйте задачи из списка
4. Зарабатывайте баллы и деньги
5. Отслеживайте прогресс

### Для родителя
1. Роль «Родитель» установлена по умолчанию
2. При первом входе придумайте PIN (4–8 цифр). Дальше он спрашивается при каждой загрузке страницы, после пяти неверных попыток вход блокируется на 30 секунд
3. Настройте параметры:
   - **Курс**: сколько рублей стоит один балл
   - **Лимит**: максимум рублей за месяц; 0 означает, что рубли не начисляются
   - **PIN**: пароль для входа в настройки
4. Добавляйте, редактируйте и удаляйте задачи
5. В разделе «Аналитика» переключайте недельный и месячный отчеты
6. Выбирайте дату в календаре, чтобы посмотреть результат и список выполненных заданий

### Как считается лимит

Дни месяца идут по порядку. Баллы каждого дня умножаются на курс, и рубли начисляются, пока не выбран лимит. Когда лимит выбран, новые баллы продолжают копиться, но рубли за них уже не начисляются. Поэтому сумма рублей по дням всегда равна месячному итогу, а в карточке дня видно, сколько реально начислено.

## Структура файлов

Все файлы лежат в одной папке, без вложенных. Так проще загружать на GitHub: веб-интерфейс сохраняет только файлы, папки при перетаскивании теряются.

```
.
├── index.html            # Главная страница
├── script.js             # Логика приложения
├── style.css             # Стили и темы
├── sw.js                 # Service Worker (офлайн)
├── manifest.json         # Манифест PWA
├── chart.umd.min.js      # Chart.js 4.4.4
├── icon-192.png          # Иконка приложения
├── icon-512.png          # Иконка приложения
├── icon-maskable-512.png # Иконка для круглых масок Android
├── apple-touch-icon.png  # Иконка для iPhone
├── favicon-32.png        # Фавикон
├── changelog.md          # Что исправлено
└── readme.md             # Документация
```

## Офлайн-режим

Service Worker кэширует оболочку приложения и Chart.js. Страница открывается без сети; новые отметки сохраняются в браузере. После правки файлов поднимите версию кэша в первой строке `sw.js` (`motivator-v2` → `motivator-v3`), иначе браузер может показать старую версию.

## Особенности дизайна

- 🎨 Современный минималистичный интерфейс
- 📱 Полностью адаптивен под мобильные устройства
- 🌈 Спокойная палитра (мята, коралл, желтый)
- ✨ Плавные анимации и переходы, отключаются при `prefers-reduced-motion`
- ♿ Доступность: контраст текста не ниже 4.5:1, видимый фокус с клавиатуры, зоны нажатия от 44 px, подписи для экранного диктора

## Браузеры

Работает в современных браузерах:
- Chrome/Edge 88+
- Firefox 90+
- Safari 15.4+

В Safari 14 и older возможны отличия в оформлении чекбоксов и размытии шапки, логика работает.
